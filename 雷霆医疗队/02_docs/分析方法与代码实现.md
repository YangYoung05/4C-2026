### 3.1 两个坐标轴

健康转型阶段用两个轴刻画：

1. 老龄化/发展轴 `ageing_axis_score`
2. 疾病负担轴 `burden_axis_score`

老龄化/发展轴使用以下变量的百分位均值：

| 变量 | 含义 |
|---|---|
| `hdi` | 人类发展指数 |
| `life_expectancy` | 预期寿命 |
| `median_age` | 中位年龄 |
| `wdi_population_65_plus_pct` | 65 岁及以上人口占比 |

代码公式：

```text
ageing_axis_score = mean(percentile(hdi),
                         percentile(life_expectancy),
                         percentile(median_age),
                         percentile(wdi_population_65_plus_pct))
```

疾病负担轴先计算四类 GBD 负担总量：

| 变量 | 含义 |
|---|---|
| `gbd_rate_cardiovascular_diseases` | 心血管疾病负担 |
| `gbd_rate_chronic_respiratory_diseases` | 慢性呼吸系统疾病负担 |
| `gbd_rate_neoplasms` | 肿瘤负担 |
| `gbd_rate_diabetes_kidney` | 糖尿病与肾病负担 |

代码公式：

```text
gbd_burden_total = cardiovascular + chronic_respiratory + neoplasms + diabetes_kidney
burden_axis_score = percentile(gbd_burden_total)
```

这里的 `percentile()` 使用 pandas `rank(pct=True, method="average")`，所以分数在 0-1 之间，值越大表示在样本中相对越高。

### 3.2 阶段分类

分类函数为 `classify_stage(ageing_score, burden_score)`：

```text
if ageing < 0.5 and burden < 0.5: 转型早期
if ageing < 0.5 and burden >= 0.5: 负担上升期
if ageing >= 0.5 and burden >= 0.5: 非传染病高压期
if ageing >= 0.5 and burden < 0.5: 高龄稳定期
```

这是一套规则型分期，不是机器学习聚类。这样做的好处是解释性强，适合答辩中说明“横轴代表转型程度，纵轴代表慢病负担压力”。

### 4.1 四个维度

脆弱性画像由四个维度组成：

| 维度 | 得分字段 | 主要变量 | 方向 |
|---|---|---|---|
| 健康负担 | `health_burden_score` | 四类 GBD 疾病负担 | 越高越脆弱 |
| 风险暴露 | `risk_exposure_score` | 吸烟、PM2.5、高 BMI、高血糖、高收缩压、膳食风险 | 越高越脆弱 |
| 系统脆弱性 | `system_fragility_score` | 医生、护士、床位、UHC、卫生支出、政府卫生支出、自付/外部依赖等 | 资源越少越脆弱，依赖越高越脆弱 |
| 社会经济脆弱性 | `socioeconomic_fragility_score` | HDI、人均 GDP、基尼、老龄化、城镇化 | 发展水平越低、不平等和老龄化压力越高越脆弱 |

### 4.2 标准化流程

每个原始变量进入聚类前会经过以下步骤：

1. 数值化：`pd.to_numeric(errors="coerce")`
2. 偏态变量做 `log1p`，如疾病负担、风险暴露、人均支出、人均 GDP
3. Winsorize：默认截尾 1% 和 99%，降低极端值影响
4. 方向统一：
   - `direction="high"`：原值越高越脆弱
   - `direction="low"`：取负号后再标准化，表示原值越低越脆弱
5. Z-score 标准化：

```text
z = (x - mean(x)) / std(x)
```

6. 每个维度取该维度内变量 z 分数均值：

```text
dimension_score = mean(z_variables_in_dimension)
```

7. 每条国家-年份记录至少需要观测到 3 个维度，才进入聚类。

### 4.3 聚类实现

聚类使用 KMeans，默认锁定 `K=3`：

```text
feature_matrix = StandardScaler().fit_transform(
    [health_burden_score,
     risk_exposure_score,
     system_fragility_score,
     socioeconomic_fragility_score]
)

labels = KMeans(n_clusters=3, random_state=42, n_init=50).fit_predict(feature_matrix)
```

代码会同时评估多个 K 值，指标包括：

| 指标 | 作用 |
|---|---|
| Silhouette | 类内紧密、类间分离程度 |
| Bootstrap stability | 重抽样后聚类标签稳定性 |
| KMeans vs Hierarchical ARI | KMeans 与层次聚类结果一致性 |
| Selection score | `silhouette + 0.25 * bootstrap + 0.15 * ARI` |

三类最终标签固定为：

| 类型 | 标签 | 含义 |
|---|---|---|
| 类型1 | `类型1-高负担转型承压型` | 健康负担和风险压力高，处于慢病转型承压阶段 |
| 类型2 | `类型2-低缓冲低承载型` | 系统承载和社会经济缓冲不足 |
| 类型3 | `类型3-相对稳健型` | 四维压力相对均衡，综合脆弱性较低 |

### 5.1 疾病和风险变量

疾病负担：

- `gbd_rate_cardiovascular_diseases_per100k`
- `gbd_rate_chronic_respiratory_diseases_per100k`
- `gbd_rate_neoplasms_per100k`
- `gbd_rate_diabetes_kidney_per100k`

风险暴露：

- `dbd_smoking_per100k`
- `dbd_pm25_per100k`
- `dbd_high_bmi_per100k`
- `dbd_high_glucose_per100k`
- `dbd_high_sbp_per100k`
- `dbd_dietary_risks_per100k`

### 5.2 回归模型

在每个脆弱性类型内部，对每个疾病负担分别回归 6 个风险因素，并加入年份虚拟变量：

```text
y_z = beta_0
    + beta_1 * smoking_z
    + beta_2 * pm25_z
    + beta_3 * high_bmi_z
    + beta_4 * high_glucose_z
    + beta_5 * high_sbp_z
    + beta_6 * dietary_risks_z
    + year fixed effects
    + error
```

实现细节：

- 连续变量默认 1%-99% winsorize
- 默认 `log1p` 转换
- y 和 x 都标准化为 z 分数
- 最小样本数为 `max(18, 风险变量数 * 3)`
- 回归用 `np.linalg.lstsq`

### 5.3 贡献权重

每个风险的贡献权重来自标准化 beta 的绝对值占比：

```text
contribution_share_i = abs(beta_i) / sum(abs(beta_all_risks))
```

热力图单元格就是 `contribution_share`。它表示“在该脆弱性类型、该疾病负担中，哪个风险解释权重更高”。

注意：风险归因矩阵是关联型归因，不是严格因果识别。

### 6.1 综合压力得分

综合压力由疾病负担压力和风险暴露压力组成：

```text
burden_pressure_score = mean(percentile(四类 GBD 疾病负担))
risk_pressure_score   = mean(percentile(六类 DBD 风险暴露))

combined_pressure_score = mean(burden_pressure_score, risk_pressure_score)
```

这里的分位数同样使用 `rank(pct=True)`，值域为 0-1。

### 6.2 资源响应得分

正向资源变量越高越好，直接取百分位：

- 病床、医生、护士
- UHC 指数
- 卫生支出/GDP、人均卫生支出、政府卫生支出
- WDI 医疗资源、WB_HNP 服务覆盖等

负向资源变量越高越差，取反向百分位：

- 外部卫生支出依赖
- 自付卫生支出占比

代码公式：

```text
component_score_positive = percentile(x)
component_score_negative = percentile(-x)
resource_response_score = mean(all_component_scores)
```

### 6.3 背景支持得分

如果存在背景变量，则计算 `context_support_score`：

- HDI
- 人均 GDP
- 基尼系数
- 65 岁以上人口占比
- 城镇化率

其中基尼系数使用反向百分位，其他变量按正向百分位。

### 6.4 调整后响应能力

默认背景权重为 `context_weight = 0.2`：

```text
adjusted_response_score =
    0.8 * resource_response_score
  + 0.2 * context_support_score
```

如果没有背景变量，则：

```text
adjusted_response_score = resource_response_score
```

### 6.5 适配缺口计算

适配缺口是本项目模块 C 的核心指标：

```text
adaptation_gap_score = combined_pressure_score - adjusted_response_score
```

解释：

- 值越大：压力高于响应能力，越需要优先干预。
- 接近 0：压力与响应基本匹配。
- 小于 0：响应能力相对超过当前压力，不代表没有问题，只代表适配压力较低。

### 6.6 响应失配类型

分类函数为 `classify_response_type(pressure, response)`：

```text
if pressure >= 0.67 and response < 0.50: 高压低响应型
if pressure >= 0.67 and response >= 0.50: 高压高响应型
if pressure < 0.50 and response < 0.50: 低压低响应型
else: 相对均衡型
```

其中：

- `0.67` 约等于上三分位阈值，用于识别高压力。
- `0.50` 是中位附近阈值，用于区分响应能力是否达到基本均衡。

## 7. 模块 C：资源补短板情景

代码位置：`c_run_abcd.py` 内部函数 `simulate_component_upgrade`

对每个国家：

1. 找到资源组件得分最低的 3 个短板。
2. 将这些组件的分位得分各提升 `0.10`。
3. 重新计算 `resource_response_score`。
4. 重新计算 `adjusted_response_score`。
5. 重新计算 `adaptation_gap_score`。

公式：

```text
optimized_component = min(1.0, component_score + 0.10)
optimized_resource_response_score = mean(updated_component_scores)
optimized_adjusted_response_score = 0.8 * optimized_resource_response_score + 0.2 * context_support_score
optimized_adaptation_gap_score = combined_pressure_score - optimized_adjusted_response_score
gap_reduction_if_upgraded = adaptation_gap_score - optimized_adaptation_gap_score
```

该情景回答“如果优先补最弱资源项，适配缺口最多能下降多少”。它不是预算约束优化，也不代表真实投入成本。

- WHO NCD 高血压、糖尿病、宫颈筛查等服务覆盖指标
- WHO MPOWER 六分项政策强度
- World Bank WDI 烟草使用率和 UHC NCD 指标
- 模块 A/B/C 输出的类型、风险、压力、响应和适配缺口

### 8.2 政策情景模拟

模块 D 输出四类情景：

| 情景 | 方法 |
|---|---|
| 资源提升 | 沿用模块 C，对短板资源分项提升 0.10 后重算缺口 |
| 风险下降 | 对主导风险设置 5%/10%/15% 下降，按贡献份额和保守转化系数折算压力下降 |
| 服务覆盖补齐 | 高血压、糖尿病等服务覆盖补到目标阈值后折算响应能力提升 |
| 政策包适配 | 按脆弱性类型、风险三元组、资源短板和相似国家生成政策优先级 |

风险下降情景的核心折算：

```text
pressure_reduction = risk_contribution_share * risk_reduction_rate * 0.35
```

其中 `0.35` 是保守转化系数，避免把风险下降情景夸大为直接健康结果因果效应。

### 8.3 模块D高级证据链

模块D准因果增强层做基础准因果增强：

- 政策事件库
- 交错 DID
- 事件研究
- 前趋势检查
- 安慰剂检验
- 合成控制
- 矩阵补全
- 中国迁移相似度

模块D多政策路径组合层做多政策组合验证：

- 控烟路径
- 高血压政策准备度
- 基层 NCD 服务
- 综合治理能力
- 膳食控盐
- 糖尿病政策准备度

模块D证据裁判与锁定层做顶层证据裁判：

```text
d6_total_score =
    0.54 * design_integrity_score
  + 0.17 * bias_sensitivity_score
  + 0.14 * mechanism_score
  + 0.10 * china_transfer_readiness_score
  + 0.05 * claim_precision_score
```

它不是把观察性政策数据包装成随机实验，而是把每条政策路径放到统一证据裁判层。

## 9. 中国省级映射

代码入口：`e_china_mapping.py`

核心定位：

```text
中国映射 = 全球 ABCD 框架在中国 31 省的压力-风险-响应-政策适配画像
```

主要输入：

| 数据 | 作用 |
|---|---|
| NBS 省级卫生人员和医疗卫生机构 | C 层资源响应核心评分 |
| 第七次人口普查人口和年龄结构 | 人口校正、老龄化压力 |
| GBD 2017 中国省级疾病 DALY 和风险 SEV | 省级疾病压力和风险压力 |
| GBD 2021 中国省级 NCD 年龄标化死亡率/DALY | 健康结局锚点和新鲜度桥接 |
| ScienceDB 342 城 PM2.5 | 环境风险暴露 |
| 2020 地级市人口权重 | PM2.5 省内人口加权聚合 |
| NHSA DRG/DIP 试点城市 | D 层省级政策暴露 |
| NHC 慢病综合防控示范区 | 慢病政策执行强度代理 |
| 地方政策执行指标 | 医保支付改革、慢病综合防控等政策包 |
| NBS OCR 字段级 QC | 床位、医保、基金收支等补充字段复核 |

### 9.1 中国资源响应得分

省级资源脚手架分数：

```text
resource_response_score =
    0.45 * staff_per_capita_percentile
  + 0.25 * institution_per_capita_percentile
  + 0.20 * staff_growth_percentile
  + 0.10 * institution_growth_percentile
```

含义：

- 人均卫生人员权重最高，因为它代表直接服务能力。
- 医疗卫生机构密度代表可及性。
- 5 年增长反映近期响应趋势。

### 9.2 中国综合压力得分

中国省级综合压力：

```text
province_combined_pressure_score =
    0.45 * province_burden_pressure_score
  + 0.35 * province_risk_exposure_score
  + 0.20 * aging65_pressure_percentile
```

其中：

- `province_burden_pressure_score` 来自 GBD 2017 四类疾病 DALY 率分位均值。
- `province_risk_exposure_score` 来自 GBD 2017 风险 SEV 和 PM2.5 风险分位。
- `aging65_pressure_percentile` 来自七普 65 岁以上人口占比分位。

### 9.3 中国省级适配缺口

```text
province_response_score = resource_response_score
province_adaptation_gap_score = province_combined_pressure_score - province_response_score
province_adaptation_gap_percentile = percentile(province_adaptation_gap_score)
```

省级响应类型：

```text
if pressure >= 2/3 and response < 0.50: 高压低响应型
if pressure >= 2/3 and response >= 0.50: 高压高响应型
if pressure < 2/3 and response < 0.50: 低压低响应型
else: 相对均衡型
```

## 11. 复现与审计

复现标准：

1. `01_main` 只运行五个正式入口。
2. 主流程不主动联网，只读 `input/External Data` 和 `09_data_clean`。
3. 所有核心结果都写入 `06_report_assets` 的六个分区目录，根目录不再平铺结果文件。
4. 所有图表写入 `05_figures`。
5. 所有关键脚本可通过 `python3 -m py_compile 01_main/*.py` 静态检查。

当前建议答辩口径：

> 我们不是用一张图或一个模型直接下结论，而是先构建全球国家-年份健康面板，再用 A 模块识别健康转型和脆弱性画像，B 模块识别主导风险链条，C 模块计算压力-响应适配缺口，D 模块把全球政策响应证据和准因果筛选转化为政策适配引擎，最后用中国省级数据做迁移映射和政策建议。
