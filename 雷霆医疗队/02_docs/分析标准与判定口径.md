### 1.3 缺失处理标准

脆弱性分型：

- 单个特征缺失率超过 `0.65`，从该模块特征集中剔除。
- 每条国家-年份记录至少需要观测到 3 个维度。
- 进入聚类前，对缺失维度用该维度中位数填补。

响应失配：

- 资源变量缺失率超过 `0.65`，视为稀疏变量剔除。
- 资源变量缺失率超过 `0.40`，不进入主响应得分。
- 缺失过多的字段可以进入审计，但不强行进入核心评分。

中国 OCR 字段：

- OCR 字段必须经过字段级 QC。
- 未通过 QC 的字段自动禁用。
- OCR 候选字段可以作为解释层或后续人工复核入口，不进入核心 C 层评分。

## 2. 健康转型阶段判定标准

健康转型阶段由两个 0-1 分位轴决定：

| 轴 | 字段 | 含义 |
|---|---|---|
| 老龄化/发展轴 | `ageing_axis_score` | HDI、预期寿命、中位年龄、65岁以上人口占比的分位均值 |
| 疾病负担轴 | `burden_axis_score` | 四类 GBD 慢病负担总量的分位 |

判定标准：

| 条件 | 阶段 |
|---|---|
| `ageing < 0.5` 且 `burden < 0.5` | 转型早期 |
| `ageing < 0.5` 且 `burden >= 0.5` | 负担上升期 |
| `ageing >= 0.5` 且 `burden >= 0.5` | 非传染病高压期 |
| `ageing >= 0.5` 且 `burden < 0.5` | 高龄稳定期 |

解释标准：

- 阶段识别是理论驱动的规则分类，不是聚类。
- `0.5` 是样本中位分位阈值，用于区分相对高/低。
- 阶段标签表示健康转型结构，不是国家发展优劣评价。

不能这样讲：

- 不能说某个国家永久处于某阶段。
- 不能说阶段本身证明政策效果。
- 不能把阶段数量变化解释成单一政策造成。

## 3. 健康脆弱性类型判定标准

### 3.1 四维得分方向

| 维度 | 高分含义 |
|---|---|
| `health_burden_score` | 疾病负担更高 |
| `risk_exposure_score` | 风险暴露更高 |
| `system_fragility_score` | 卫生系统承载更弱或支付结构更脆弱 |
| `socioeconomic_fragility_score` | 社会经济缓冲更弱或老龄化/不平等压力更高 |

所有维度都被统一为“越高越脆弱”。

### 3.2 聚类数标准

主方案锁定 `K=3`。

判断依据：

| 指标 | 判定用途 |
|---|---|
| Silhouette | 分型是否有分离度 |
| Bootstrap stability | 分型是否稳定 |
| KMeans-Hierarchical ARI | 不同聚类方法是否一致 |
| 可解释性 | 是否能形成清晰的政策画像 |

项目选择 K=3 的原因：

1. 三类能覆盖“高负担转型承压”“低缓冲低承载”“相对稳健”三种政策含义。
2. 类别数量适合答辩表达，不会过度碎片化。
3. 稳定性指标较好，Bootstrap 稳定性可防守。

### 3.3 三类标签标准

| 类型 | 判定画像 | 答辩解释 |
|---|---|---|
| 类型1-高负担转型承压型 | 健康负担、风险暴露或系统压力较高 | 慢病转型压力突出，需要风险治理和资源响应共同推进 |
| 类型2-低缓冲低承载型 | 系统承载和社会经济缓冲不足 | 基础资源、服务覆盖和财政韧性是首要约束 |
| 类型3-相对稳健型 | 四维压力相对均衡 | 整体承压较低，但仍可能存在局部风险或资源短板 |

不能这样讲：

- 不能说类型3没有健康问题。
- 不能把类型1理解为“最差国家”。
- 不能说聚类标签是政策因果结果。

## 4. 风险归因判定标准

风险归因矩阵中的单元格是：

```text
contribution_share_i = abs(standardized_beta_i) / sum(abs(standardized_beta_all_risks))
```

解释标准：

| 指标 | 含义 |
|---|---|
| `standardized_beta` | 在同一疾病、同一脆弱性类型内部，风险变量与疾病负担的标准化关联方向和大小 |
| `absolute_beta` | 关联强度绝对值 |
| `contribution_share` | 该风险在所有风险解释权重中的占比 |
| `rank_in_disease` | 某疾病内风险贡献排名 |

主导风险判定：

- 每个类型、每个疾病中，`rank_in_disease = 1` 的风险为该疾病主导风险。
- 类型层面的 `dominant_risk_triplet` 取贡献排名靠前的风险，形成答辩用风险三元组。

可以这样讲：

> 风险归因矩阵用于识别不同脆弱性类型中，哪些风险和疾病负担结构关联最强，从而确定前移治理优先级。

不能这样讲：

- 不能说某个风险的 `contribution_share=40%` 就代表它因果造成了 40% 疾病负担。
- 不能把标准化回归权重解释为医学因果效应。
- 不能用该矩阵替代 GBD 官方归因分解。

## 5. 响应失配与适配缺口判定标准

### 5.1 核心公式

```text
combined_pressure_score = mean(burden_pressure_score, risk_pressure_score)
adjusted_response_score = 0.8 * resource_response_score + 0.2 * context_support_score
adaptation_gap_score = combined_pressure_score - adjusted_response_score
```

如果没有背景支持变量：

```text
adjusted_response_score = resource_response_score
```

### 5.2 适配缺口解释标准

| `adaptation_gap_score` | 解释 |
|---|---|
| 大于 0 | 压力高于响应能力，存在适配缺口 |
| 接近 0 | 压力和响应大致匹配 |
| 小于 0 | 响应能力相对高于压力，不代表没有健康风险 |

Top20 适配缺口国家不是“疾病负担最高国家”，而是：

```text
压力高 + 响应弱 + 两者不匹配
```

### 5.3 响应失配类型标准

| 条件 | 类型 | 含义 |
|---|---|---|
| `pressure >= 0.67` 且 `response < 0.50` | 高压低响应型 | 最优先关注，压力高但响应能力不足 |
| `pressure >= 0.67` 且 `response >= 0.50` | 高压高响应型 | 压力高但已有一定响应能力，重点是效率和精准治理 |
| `pressure < 0.50` 且 `response < 0.50` | 低压低响应型 | 当前压力不高但基础能力弱，需防止未来承压 |
| 其他情况 | 相对均衡型 | 压力和响应相对平衡，但仍可能有局部短板 |

阈值来源：

- `0.67` 约等于上三分位，表示相对高压力。
- `0.50` 是中位附近，表示响应能力是否达到基本均衡。

答辩口径：

> 响应失配不是单纯比较资源多少，而是同时比较健康压力和响应能力。高压低响应型优先级最高，因为它的健康压力已经较高，但资源和系统响应不足。

## 6. 资源补短板情景判定标准

默认情景：

- 每个国家选择最低的 3 个资源组件。
- 每个短板组件分位得分提升 `0.10`。
- 重新计算响应得分和适配缺口。

关键字段：

| 字段 | 含义 |
|---|---|
| `scenario_target_components` | 被提升的短板资源 |
| `optimized_adjusted_response_score` | 情景后的调整响应能力 |
| `optimized_adaptation_gap_score` | 情景后的适配缺口 |
| `gap_reduction_if_upgraded` | 缺口缩减潜力 |
| `response_lift_needed_to_balance` | 达到 0.50 基本均衡还需要的响应提升 |

解释边界：

- 这是“优先补什么”的策略模拟。
- 不是预算优化。
- 不代表真实财政投入量。
- 不代表政策实施后必然达到该缺口缩减。

## 7. 模块 D 政策证据判定标准

### 7.1 模块D准因果增强层证据阶梯

模块D准因果增强层将每条政策路径放入证据阶梯：

```text
evidence_score =
    0.35 * quasi_causal_signal
  + 0.20 * pretrend_pass
  + 0.15 * placebo_pass
  + 0.15 * synthetic_support
  + 0.15 * matrix_support
```

等级：

| `evidence_score` | 等级 |
|---|---|
| `<= 0.35` | 探索性相关证据 |
| `(0.35, 0.60]` | 准因果弱证据 |
| `(0.60, 0.80]` | 准因果中等证据 |
| `> 0.80` | 准因果强候选 |

可提升为因果路径候选必须同时满足：

- 有准因果信号。
- 方向符合预期。
- 前趋势通过。
- 安慰剂通过。

### 7.2 模块D多政策路径组合层判定

模块D多政策路径组合层不再只看控烟，而是把控烟、高血压、基层 NCD 服务、综合治理能力、控盐、糖尿病等路径统一放入政策组合。

等级：

| 条件 | 多政策路径等级 | 解释 |
|---|---|---|
| `d5_score >= 0.80` 且方向一致、前趋势通过、wild 或 cohort 通过 | 准因果强候选 | 可作为模块 D 主证据路径，但不能写成随机实验 |
| `d5_score >= 0.70` 且方向一致、稳健检查数 >= 4 | 稳健政策候选 | 可作备选主线或旁证 |
| `d5_score >= 0.55` 且方向一致 | 政策适配候选 | 可进入政策包和情景模拟 |
| 其他 | 探索性证据 | 只能作解释或敏感性材料 |

### 7.3 模块D证据裁判与锁定层标准

顶层证据总分：

```text
d6_total_score =
    0.54 * design_integrity_score
  + 0.17 * bias_sensitivity_score
  + 0.14 * mechanism_score
  + 0.10 * china_transfer_readiness_score
  + 0.05 * claim_precision_score
```

证据裁判等级：

| 条件 | 等级 | 使用方式 |
|---|---|---|
| `score >= 0.86` 且 `design >= 0.78` 且 `bias >= 0.70` 且 `claim >= 0.85` | 金牌主证据 | 模块 D 最强主证据，严格准因果强候选 |
| `score >= 0.76` 且 `design >= 0.68` | 银牌强候选 | 备选强候选或主证据旁证 |
| `score >= 0.64` | 铜牌适配候选 | 进入政策包和中国情景模拟 |
| 其他 | 机制/探索证据 | 只作解释、敏感性或探索材料 |

最重要的边界：

> 模块D证据裁判与锁定层是严格准因果证据裁判层，不是随机实验级强因果。

不能这样讲：

- 不能说模块D证据裁判与锁定层等同 RCT。
- 不能说服务覆盖改善已经证明死亡率或 DALY 下降。
- 不能用中国省级映射反向证明全球政策因果。

## 8. 中国省级映射判定标准

### 8.1 省级资源响应分类

资源脚手架得分：

```text
resource_response_score =
    0.45 * 人均卫生人员分位
  + 0.25 * 人均医疗机构分位
  + 0.20 * 卫生人员5年增长分位
  + 0.10 * 医疗机构5年增长分位
```

资源类型：

| 条件 | 类型 |
|---|---|
| `< 1/3` | 人均资源低位 |
| `1/3 - 2/3` | 人均资源中位 |
| `>= 2/3` | 人均资源高位 |

### 8.2 省级综合压力分类

省级综合压力：

```text
province_combined_pressure_score =
    0.45 * 疾病负担压力
  + 0.35 * 风险暴露压力
  + 0.20 * 老龄化压力
```

压力类型：

| 条件 | 类型 |
|---|---|
| `< 1/3` | 省级压力低位 |
| `1/3 - 2/3` | 省级压力中位 |
| `>= 2/3` | 省级压力高位 |

### 8.3 省级适配缺口和类型

```text
province_adaptation_gap_score =
    province_combined_pressure_score - province_response_score
```

省级响应类型：

| 条件 | 类型 |
|---|---|
| `pressure >= 2/3` 且 `response < 0.50` | 高压低响应型 |
| `pressure >= 2/3` 且 `response >= 0.50` | 高压高响应型 |
| `pressure < 2/3` 且 `response < 0.50` | 低压低响应型 |
| 其他 | 相对均衡型 |

### 8.4 省级政策暴露分类

D 层政策得分综合：

- NHSA DRG/DIP 政策暴露。
- NHC 慢病综合防控示范区执行强度。
- 地方政策执行指标。

分类：

| 条件 | 类型 |
|---|---|
| `< 1/3` | D层政策暴露低位 |
| `1/3 - 2/3` | D层政策暴露中位 |
| `>= 2/3` | D层政策暴露高位 |

解释边界：

- DRG/DIP 用于政策暴露和资源响应准因果候选。
- NBS 粗死亡率只是健康结局敏感性，不是年龄标化 NCD 结局。
- 中国省级政策不能被表述为已经因果降低死亡率或 DALY。

## 9. 图表使用标准

正文图标准：

- 必须直接支撑主结论。
- 必须能说明 A/B/C/D 闭环。
- 优先使用解释性强的图：阶段散点、四维画像、风险归因、压力-响应、适配缺口、政策证据。

附录图标准：

- 用于稳健性、审计、过程说明。
- 不作为第一结论。
- 可在答辩被追问时展示。

不建议作为核心图：

- 纯代码截图。
- 信息量低的普通柱状图或折线图。
- 未中文化、标题不清、灰色区域解释不清的旧图。
- DID 不显著的图放在显眼位置并写成主因果结论。

## 10. 答辩总口径

### 10.1 可以说

1. 我们构建了全球国家-年份健康转型面板。
2. 我们用 A/B/C 模块识别健康脆弱性、主导风险和压力-响应适配缺口。
3. 适配缺口是“健康压力”和“响应能力”的差，不是单纯疾病负担排名。
4. 模块 D 已从单一控烟 DID 升级为多政策路径适配引擎。
5. 模块D证据裁判与锁定层能把每条政策路径按设计完整性、偏误敏感性、机制链、迁移适配和声明边界统一裁判。
6. 中国映射是全球框架的省级应用层，已形成 31 省压力-风险-响应-政策适配画像。

### 10.2 不能说

1. 不能说所有政策已经被证明强因果有效。
2. 不能说模块D证据裁判与锁定层是随机实验。
3. 不能说服务覆盖改善等同于死亡率下降。
4. 不能说中国省级政策已经因果降低 DALY 或死亡率。
5. 不能把风险归因矩阵解释成医学因果归因。
6. 不能用中国映射反向证明全球模块 D。

### 10.3 一句话版本

> 我们的核心不是把某一个政策 p 值做显著，而是建立“健康压力识别-风险归因-响应失配-政策适配”的闭环：A 判断国家或省份处于哪类健康脆弱性，B 找主导风险，C 计算适配缺口，D 用全球政策证据和准因果裁判输出可迁移、可解释、可防守的政策优先级。
